# Information Retrieval System using TF-IDF

##  Project Overview

This project implements an Information Retrieval system using the **TF-IDF (Term Frequency–Inverse Document Frequency)** technique. The system takes a user's query and ranks the documents in the dataset according to their relevance to the query.

##  Objectives

* Retrieve relevant documents based on a user query.
* Calculate TF-IDF values for the documents.
* Rank documents according to their relevance.
* Display the TF-IDF values and retrieval results.

##  Dataset

The project uses the **BBC News dataset**, which contains text documents from different news categories.

##  Technologies Used

* Python
* Google Colab
* Pandas
* NumPy
* Scikit-learn
* TF-IDF Vectorization

##  Methodology

1. Load the BBC News dataset.
2. Preprocess the text documents.
3. Convert documents into TF-IDF vectors.
4. Accept a query from the user.
5. Convert the query into a TF-IDF vector.
6. Calculate similarity between the query and documents.
7. Rank the documents based on their relevance.
8. Display the retrieved documents and TF-IDF values.

##  Output

The project produces:

* Ranked documents based on the user's query.
* TF-IDF values.
* Retrieval results showing the most relevant documents.

The complete output is available in `ir output.pdf`.

##  Files

* `IR_1.ipynb` – Google Colab notebook containing the implementation.
* `bbc_news.csv` – Dataset used for the project.
* `ir output.pdf` – Output and results of the project.
